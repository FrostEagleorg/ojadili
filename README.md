# Ojadili

Companion site for *Ojadili, Book One: The Back That Never Touched the Ground* by Dubem Gbuzue.
Astro, deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

## Before going live
- `src/config.ts`: domain, contact email, Amazon paperback and Kindle links
- `astro.config.mjs`, `public/CNAME`, `public/robots.txt`: domain
- `public/images/`: replace the placeholders (cover.jpg, ojadili.jpg, chidi.jpg, nne-nne.jpg, map-umuagu.jpg)
- `public/downloads/ojadili-activity-page.pdf`: the activity page

## Run locally
npm install, then npm run dev
